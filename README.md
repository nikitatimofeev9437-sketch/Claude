# SemiReal Studio

Локальная программа для генерации изображений 18+ в semi-realistic стиле. Работает на модели SDXL через
библиотеку `diffusers` и запускается в окне на Windows. Настроена под **RTX 4070 Laptop (8 ГБ VRAM) и 32 ГБ ОЗУ**.
Всё работает офлайн на вашем компьютере. Интернет нужен только при установке и при первом использовании
отдельных функций: тогда программа один раз скачивает небольшие вспомогательные модели.

## Возможности

| Функция | Что делает |
|---|---|
| Текст → изображение | Генерация по промпту. Поддерживаются веса `(слово:1.3)`, `[слово]` и `BREAK`, длина промпта не ограничена |
| Пресеты стиля | Готовые префиксы и негативы для semi-realistic под Pony, Illustrious и обычный SDXL (`presets/styles.json`) |
| LoRA | Можно подключить несколько LoRA сразу, у каждой свой вес |
| Поза | OpenPose через T2I-Adapter (~300 МБ, помещается в 8 ГБ). Можно взять готовый скелет или извлечь позу из любого фото |
| Img2img | Перерисовка по исходной картинке |
| Inpaint | Рисуете маску кистью и перерисовываете эту область. Есть режим «только область маски» для мелких деталей |
| Outpaint | Расширение картинки в любую сторону с дорисовкой |
| Hires fix | Увеличение (Lanczos или ESRGAN-модель, например 4x-UltraSharp) и второй проход для детализации |
| Исправление лиц и рук | Как ADetailer: YOLO находит лица и руки, затем каждая область перерисовывается в высоком разрешении |
| Метаданные | Каждая картинка сохраняется в `outputs/ГГГГ-ММ-ДД/` с параметрами в PNG, как в A1111 |

## Установка (Windows 11)

1. Поставьте **Python 3.12** с [python.org](https://www.python.org/downloads/). При установке отметьте
   «Add python.exe to PATH».
2. Обновите драйвер NVIDIA (версия 570 или новее).
3. Скачайте или клонируйте эту папку и запустите **`install.bat`**. Он поставит PyTorch с CUDA и все библиотеки,
   это примерно 5 ГБ. В конце скрипт должен написать `CUDA: True NVIDIA GeForce RTX 4070 Laptop GPU`.
4. Положите модель (`.safetensors`, SDXL) в `models\checkpoints\`.
5. Запустите **`run.bat`**.

## Какие модели скачать

Все файлы кладутся в подпапки `models\`:

| Папка | Что класть | Где брать |
|---|---|---|
| `checkpoints` | SDXL-чекпоинт, 6–7 ГБ | Civitai: фильтр *Checkpoint → SDXL / Pony / Illustrious* и поиск «semi-real». Подойдут, например, Pony Realism, CyberRealistic Pony и семейство Lustify. Чекпоинты SD 1.5 и Flux программа не поддерживает |
| `loras` | LoRA под ту же базу, что и чекпоинт (Pony-LoRA для Pony-моделей и т.д.) | Civitai |
| `upscalers` | `4x-UltraSharp.pth`, `RealESRGAN_x4plus.pth` и т.п. | OpenModelDB, GitHub Real-ESRGAN |
| `poses` | Картинки-скелеты OpenPose: цветные «палочки» на чёрном фоне | Civitai, поиск «openpose pose pack». Можно использовать и обычное фото, программа сама извлечёт из него позу |

Вспомогательные модели скачиваются сами при первом использовании и хранятся в `models\hf_cache` и `models\detectors`:

- конфиг SDXL (несколько КБ);
- VAE fp16-fix (~330 МБ);
- адаптер позы (~300 МБ);
- детекторы лиц и рук (по 6 МБ);
- извлекатель позы из фото (~200 МБ).

## Как пользоваться

1. Выберите чекпоинт и подходящий ему **пресет**: для Pony-моделей «Pony — Semi-realistic», для Illustrious свой
   пресет и т.д. Пресет сам выставит сэмплер, число шагов и CFG.
2. Промпт пишите на английском. Пресет добавит к нему теги качества и негатив.
3. Нажмите **Сгенерировать** или Ctrl+Enter. Результат появится справа. Кнопками под картинкой её можно
   отправить в Img2img, Inpaint или Outpaint.
4. **Inpaint:** на вкладке «Исходник / маска» левая кнопка мыши рисует маску, правая стирает, колесо меняет
   размер кисти.
5. **Outpaint:** укажите, на сколько пикселей расширить картинку с каждой стороны (лучше по 128–384 за раз).
   Сила оставьте 1.0.

### Библиотека промптов и параметры из картинок

- **Библиотека** (вкладка «Основное»). «Сохранить текущее…» запоминает промпт вместе со всеми настройками:
  пресет, размер, сэмплер, LoRA, hires, детейлер. «Загрузить» возвращает всё одним кликом. Результат Grok
  можно сохранить прямо со вкладки «Grok». Библиотека хранится в `prompts.json` рядом с программой.
- **Параметры из PNG.** Кнопка «Из PNG…», кнопка «Параметры → в поля» под результатом или просто перетащите
  картинку в окно. Подходят картинки этой программы, а также A1111 и Forge, в том числе теги `<lora:имя:вес>`.
  Пресет переключается на «Без пресета», потому что теги стиля уже есть в сохранённом промпте. Если нужной LoRA
  или модели нет в папках, программа об этом скажет.
- Если перетащить картинку на вкладку «Исходник / маска» (или картинку без параметров), она станет исходником
  для img2img.

### Помощник Grok (вкладка «Grok»)

Опишите сцену по-русски. Grok напишет английский промпт под выбранный пресет и, если нужно, подберёт настройки:
размер, шаги, CFG, сэмплер, hires, исправление лиц и рук. Всё сразу подставляется в поля.

- **Через подписку SuperGrok / X Premium.** Кнопка 1 копирует запрос и открывает grok.com. Вставьте запрос в чат,
  скопируйте ответ Grok кнопкой «Копировать» и нажмите кнопку 2.
- **Через API (необязательно).** Ключ с console.x.ai оплачивается **отдельно** от подписки, подписка API не даёт.
  С ключом всё происходит одной кнопкой. Ключ хранится открытым текстом в `settings.json`.

Ответ Grok проходит тот же фильтр контента, что и ручной ввод.

### Время генерации на RTX 4070 Laptop 8 ГБ

| Что | Примерно |
|---|---|
| 832×1216, 28 шагов | 20–40 с |
| + Hires ×1.5 | +60–90 с |
| + исправление лиц/рук | +10–20 с на каждую найденную область |
| Самый тяжёлый вариант (поза + hires + лица + руки) | 2,5–4 мин, в пределах 5 минут |

Первая генерация после запуска дольше на 30–60 с, потому что модель загружается в память.

### Память

- **Экономия VRAM** (по умолчанию): части модели по очереди переезжают между ОЗУ и видеокартой. Работает на 8 ГБ
  стабильно, 32 ГБ ОЗУ для этого хватает с запасом.
- **Всё в видеопамяти:** немного быстрее, но на 8 ГБ впритык. Если драйвер начнёт использовать общую память,
  генерация сильно замедлится.

## Ограничения контента

Программа предназначена только для изображений **вымышленных взрослых персонажей**.

- Промпты и имена файлов LoRA проверяются на слова, связанные с несовершеннолетними (на английском и русском).
  Такой запрос отклоняется.
- В негативный промпт всегда добавляются возрастные термины.
- Эти правила зашиты в код (`studio/core/safety.py`) и в настройках не отключаются.
- Не создавайте откровенные изображения реальных людей без их согласия: во многих странах это незаконно.

## Если что-то не так

| Проблема | Решение |
|---|---|
| Чёрные или серые картинки | Включите «VAE fp16-fix» (включён по умолчанию) |
| «Не хватило видеопамяти» | Режим «Экономия VRAM», уменьшите размер или масштаб Hires, закройте браузер и игры |
| `CUDA: False` после установки | Обновите драйвер NVIDIA и перезапустите `install.bat` |
| Модель не появляется в списке | Нужен файл `.safetensors` или `.ckpt` в `models\checkpoints`, затем нажмите ⟳ |
| Лица всё равно кривые | Сила исправления 0.35–0.5 и короткий промпт для лица, например `detailed face, beautiful eyes` |
| Позу плохо слушается | Сила позы 1.0–1.2, размер кадра под пропорции скелета. Pony-модели слушаются позу хуже, чем обычный SDXL |

## Структура

```
app.py                  точка входа
studio/core/engine.py   генерация: пайплайны SDXL, LoRA, hires, детейлер, inpaint/outpaint
studio/core/prompting.py веса промпта в стиле A1111, длинные промпты
studio/core/imaging.py  апскейл, холст для outpaint, детекция лиц/рук, поза
studio/core/safety.py   фильтр контента
studio/core/assistant.py помощник Grok: запрос и разбор ответа
studio/core/library.py  библиотека промптов
studio/core/pnginfo.py  чтение параметров из PNG (свои, A1111, Forge)
studio/ui/              окно на PySide6
presets/styles.json     пресеты стилей (можно дописывать свои)
tests/                  смоук-тест на крошечной модели (pytest, на CPU)
```
